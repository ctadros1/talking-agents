# Scientific scope and deviations

This public snapshot preserves the original experiment source, frozen configurations, pre-registrations, result tables and final representative model weights. Administrative planning history is excluded.

The v1 train-only pilot selected the cue-information objective before the frozen benchmark. The vocal channel is exploratory and has a longer budget. V2 was separately pre-registered; its communication criterion passed and its generalization criterion failed. Its restricted unseen target support permits identification shortcuts, as documented by the source-only support calculation.

On November 9, 2026, a separate full-budget twenty-seed IPPO comparison removed only the signalling objective. Original benchmark and pilot outcomes had already been seen. The comparison is post-hoc exploratory, with no tuning, early stopping, checkpoint selection or overwriting of original artifacts. The immutable declaration is SUPPLEMENTARY_ABLATION.md.

The evaluator's supplementary CSV bytes are preserved without Git line-ending normalization so that its recorded SHA-256 matches. No row values or estimates changed.

The public browser sandbox is an interactive port, outside all frozen confirmatory claims. Its client-side random generator and floating-point execution differ from PyTorch; individual browser outcomes are illustrations, never added to the benchmark.
